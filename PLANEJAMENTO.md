# CareerOS - SSOT Manager

## Objetivo

Desenvolver uma aplicação Full Stack para gerenciamento de conhecimentos organizados por categorias.

## Tecnologias

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Lombok
- PostgreSQL

### Frontend
- Angular
- Angular Material

## Entidades

### Categoria
- id
- nome

### Conhecimento
- id
- titulo
- descricao
- categoria

## Relacionamento

Uma Categoria possui vários Conhecimentos.

Um Conhecimento pertence a uma Categoria.

## Funcionalidades MVP

### Categorias
- Cadastrar
- Listar

### Conhecimentos
- Cadastrar
- Listar
